# The War for San Francisco: 7-Inch Trophy

**[Open the interactive 3D viewer](https://cichonship.github.io/war-for-san-francisco-trophy/)**

- Exactly 7 inches (177.8 mm) tall, approximately 119.64 mm across.
- Midnight-blue open cup, red bridge sleeve and sculpted gold football with pointed ends, panel seams and eight raised curved laces.
- 2022–2025 champion tags modeled with raised lettering and installed in the assembled view. Four spare slots remain.

Rotate the model, inspect the football or champion tags, switch to exploded view, or inspect the five print beds.

## Downloads

The website provides an assembled GLB, an assembled review-only 3MF, five Bambu Studio print projects, nine individual STL models and fit-test coupons.

**Prototype:** geometry, STL round trips and slicer checks passed. Physical fit, sleeve printing and small lettering still require test prints. The assembled review 3MF is not a single-piece print layout.

Estimated in Bambu Studio for an A1 with 0.4 mm nozzle: about 8 h 18 min, 182 g and nine in-print color changes. Startup and purge accounting may add material. Re-slice with the actual filament profiles before printing.

The 2024 printed tag is shortened to `2024 / BUFF BOYS / ALL GROWN UP` and omits the trademark mark.

## Implementation

Static Three.js viewer. No accounts, analytics, remote libraries or server backend are required. All model and script assets are hosted in this repository. Nine model/color/DOM tests passed; WebGL rendering was not browser-automated. Third-party license text is in `Third Party Notices.md`.
